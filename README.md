# 🌐 Multi-Explorer

Multi-Explorer is a multi-window explorer program designed to maximize your productivity. By allowing you to open and manage multiple windows simultaneously, it provides a seamless multitasking environment with an intuitive interface and various user-friendly features.

## ✨ Features

*   **Multi-Window Support:** Independently run and freely arrange multiple windows within a single application.
*   **Customizable Convenience Features:** 
    *   Screen splitting and pinning for custom layouts.
    *   Bookmarks and tab saving for frequently used folders and websites.
    *   File comparison support between explorer windows.
*   **Intuitive UI:** Features a clean and straightforward design that anyone can easily use without the need for complex configurations.

## 🚀 Installation & Usage

**Using the Executable**
1. Download the latest version from the [Releases] page on the right sidebar.
2. Extract the downloaded archive and run `[MultiExplorer.exe]`.
